# Каталог фильмов (Movie Catalog API)

## Краткое описание проекта

Веб-приложение REST API для управления каталогом фильмов. Проект позволяет просматривать, добавлять, редактировать и удалять информацию о фильмах, а также искать, фильтровать и сортировать их по различным критериям.

---

## Основные возможности приложения

- Полный цикл CRUD-операций для управления каталогом фильмов (создание, чтение, обновление, удаление).  
- Фильтрация фильмов по жанрам, году выпуска и минимальному рейтингу.  
- Сортировка по дате добавления, году выпуска, названию и рейтингу.  
- Пагинация результатов выдачи.  
- Валидация входных данных и обработка ошибок.  
- Автоматическая документация API с помощью Swagger UI и ReDoc.

---

## Технологический стек

- **Python 3.10+**  
- **FastAPI** — асинхронный веб\-фреймворк для создания API.  
- **Uvicorn** — ASGI-сервер.  
- **SQLAlchemy** — ORM для работы с базой данных.  
- **Alembic** — инструмент для управления миграциями БД.  
- **Pydantic** — валидация данных и сериализация.  
- **SQLite / PostgreSQL** — база данных.

## Быстрый старт

### 1\. Клонирование репозитория

```sh
git clone https://github.com/your-username/movie-catalog.git
cd movie-catalog
```

### 2\. Настройка виртуального окружения

```sh
python -m venv venv

# Для Linux/macOS:
source venv/bin/activate

# Для Windows:
venv\Scripts\activate
```

### 3\. Установка зависимостей

```sh
pip install -r requirements.txt
```

### 4\. Применение миграций базы данных

```sh
alembic upgrade head
```

### 5\. Запуск приложения через Uvicorn

```sh
uvicorn app.main:app --reload
```

После запуска документация Swagger UI будет доступна по адресу: `http://127.0.0.1:8000/docs`

## Основные эндпоинты

| Метод | Эндпоинт | Описание |
| :---- | :---- | :---- |
| `GET` | `/api/movies/` | Получение списка всех фильмов (с поддержкой фильтрации, сортировки и пагинации) |
| `GET` | `/api/movies/{movie_id}` | Получение подробной информации о конкретном фильме по ID |
| `POST` | `/api/movies/` | Добавление нового фильма |
| `PUT` | `/api/movies/{movie_id}` | Полное обновление информации о фильме |
| `DELETE` | `/api/movies/{movie_id}` | Удаление фильма по ID |

## Фильтрация и сортировка

При запросе `GET /api/movies/` доступны следующие параметры query:

- **Фильтрация:**  
  - `genre` — фильтрация по жанру (например, `?genre=Sci-Fi`).  
  - `year` — фильтрация по году выпуска (например, `?year=2023`).  
  - `min_rating` — фильтр фильмов с рейтингом не ниже указанного (например, `?min_rating=8.0`).  
- **Сортировка:**  
  - `sort_by` — поле для сортировки (`title`, `year`, `rating`, `created_at`).  
  - `order` — направление сортировки (`asc` — по возрастанию, `desc` — по убыванию).

*Пример запроса:* `GET /api/movies/?genre=Action&min_rating=7.5&sort_by=rating&order=desc`

## Модель данных

### Сущность `Movie`:

- `id` (`Integer`): Уникальный идентификатор фильма (Primary Key).  
- `title` (`String`): Название фильма (обязательное поле).  
- `description` (`Text`): Описание / аннотация к фильму.  
- `year` (`Integer`): Год выпуска.  
- `genre` (`String`): Жанр фильма.  
- `director` (`String`): Режиссер.  
- `rating` (`Float`): Рейтинг фильма (от 0.0 до 10.0).  
- `created_at` (`DateTime`): Дата и время добавления записи.

---

## Ограничения базы данных

- **`id`**: Первичный ключ (`PRIMARY KEY`), генерируется автоматически.  
- **`title`**: Обязательное поле (`NOT NULL`), ограничение по длине (не более 255 символов).  
- **`year`**: Поле не может быть пустым (`NOT NULL`), допустимые значения от 1888 до текущего года.  
- **`rating`**: Ограничение `CHECK (rating >= 0.0 AND rating <= 10.0)`.
